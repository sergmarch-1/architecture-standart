| 5   | Отправка СМС-уведомления клиенту о подтверждении ставки и открытии депозита                              |   Интеграция с имеющимся СМС-шлюзом        |

| U   | Удобство использования (Usability) |              |
| 1   | Интерфейсы соответствуют принятой системе дизайна приложений                                             |           |
| 2   | Улучшение скорости отклика в интерфейсе                                                          |   Сейчас некоторые справочные данные загружаются дольше секунды    |

| 1   | Время отклика операция в интерфейсе - миллисекунды                                                       |    См. U2      |
| 2   | АБС не должна перегружаться при увеличении заявок                                                        |    См. R2      |

| S   | Поддерживаемость (Supportability)  |              |
| 1   | Используются только технологии, совместимые с IT-ландшафтом банка                                        |   MS SQL, Oracle, Kafka (перспектива)        |
| 2   | Разработана документация для будущего расширения системы                                                 |           |

| +R  | + Ограничения (Restricitions)      |              |
| 1   | Интернет-банк должен быть подготовлен к масштабированию                                                  |   Перевод депозитов на микросервисную архитектуру  |
| 2   | Защита данных на сайте и в интернет-банке                                                                |   Шифрование трафика и хранения данных        |
